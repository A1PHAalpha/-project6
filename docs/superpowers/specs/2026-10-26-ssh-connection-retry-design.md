# 采集 SSH 连接重试设计

## 背景

真实采集 HQ-R1 时出现一次：

```text
Connected (version 2.0, client Cisco-1.25)
NetmikoTimeoutException: Paramiko: 'No existing session'
```

单独重试后同一设备 6/6 命令成功。说明这是瞬态连接问题，但当前采集器会立即
把设备标记为不可达，产生错误证据。

## 目标

1. 对瞬态 SSH 连接失败默认重试 1 次；
2. 认证失败不重试，避免账号锁定和无意义等待；
3. 重试次数和间隔可通过环境变量配置；
4. 保持现有采集结果结构和错误码兼容；
5. 不改变只读命令白名单。

## 非目标

- 不重试单条命令执行失败；
- 不实现指数退避队列；
- 不改 SNMP 重试；
- 不修改数据库结构。

## 验收

- 第一次连接超时、第二次成功时，设备采集成功，调用连接函数 2 次；
- 认证失败时只尝试 1 次，结果仍为 `ssh_connection_failed`；
- 重试日志包含设备名和尝试次数；
- 真实 HQ-R1 采集仍成功。
